# alipatti

Personal Python helpers.

```sh
uv add "alipatti @ git+https://github.com/alipatti/alipatti.py"
```

The package has a few extras
which can be installed with `... alipatti[<extra>] ...`
and imported at `alipatti.<extra>`

- `plot` (plotnine theme and helpers)
- `cache` (parquet cache for polars dataframes and lazyframes)
